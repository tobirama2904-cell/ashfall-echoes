# Пепел: Эхо маяка

**Оригинальный браузерный 3D survival-adventure пролог**, созданный на базе [xaidan777/ArcEngine](https://github.com/xaidan777/ArcEngine). Это не копия *The Last of Us*: мир, герои, история, визуал и звук — самостоятельные.

> В долине любой громкий звук зовёт Тишину. Курьер Мира получает радиосигнал от старого маяка и должна собрать три резонансные ячейки, пока долина не услышала её первой.

## Что уже есть в вертикальном срезе

- атмосферная 3D-локация: убежище, рельсы, заброшенная станция, мост, лес и маяк;
- сюжетный пролог с радиодиалогами, записками-памятями и финальным твистом;
- герой с анимациями idle/run;
- стелс: ходьба, бег, тихий шаг, индикатор шума и враги «Тишина»;
- патрулирование, поиск источника шума, преследование, урон и возвращение к убежищу;
- импульс, временно дезориентирующий врагов;
- звуковая приманка для отвлечения врагов;
- ящики с ресурсами, интерактивный огонь, три квестовые ячейки и маяк;
- оригинальная обложка, процедурные атмосферные звуки, музыка-эмбиент и 3D-звук;
- полноценный HUD, главное меню, финальный экран и повторное прохождение;
- локальные ассеты — нет CDN, npm-зависимостей или внешних запросов во время игры.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | движение относительно камеры |
| `Shift` | бег — шумный, расходует выносливость |
| `C` | тихий шаг / приседание |
| `E` | взаимодействие, пропуск реплики |
| `Q` | импульс — оглушает врагов в радиусе |
| `F` | бросить звуковую приманку |
| ПКМ + движение мыши | повернуть камеру |
| Колесо мыши | приблизить / отдалить камеру |
| `Esc` | пауза |

### На смартфоне

Игра теперь адаптирована для **Poco F4 / Android**. Поверните телефон в горизонтальный режим: слева появится виртуальный стик, справа — кнопки `БЕГ`, `ТИХО`, `Q`, `F` и `E`. Проведите пальцем по правой части экрана вне кнопок, чтобы повернуть камеру. В портретной ориентации игра попросит повернуть устройство.

## Запуск

Нужен только Node.js.

```bash
node tools/dev-server.mjs --no-open
# открыть http://localhost:8080/
```

На Windows можно запустить `run.bat`. Для настройки локации и HUD есть встроенный редактор ArcEngine: `editor.bat`.

## Проверка и сборка

```bash
node tools/check.mjs       # типы + 80 автоматических тестов
node tools/build.mjs       # упаковывает самостоятельную веб-версию
```

Готовый архив находится в [`release/ashfall-echoes-v0.2.1.zip`](release/ashfall-echoes-v0.2.1.zip). Его можно распаковать на любом статическом хостинге или открыть через локальный HTTP-сервер.
